# smart-push-monitor
Отказоустойчивый Bash-скрипт для продвинутого мониторинга VPN-узлов (Reality, VLESS, Hysteria 2) с интеграцией в Uptime Kuma (Push-тип)


🚀 Основные возможностиГибридная проверка (L3-L7): Скрипт проверяет не только наличие процесса, но и реальную проходимость трафика (TCP/UDP) и валидность TLS-рукопожатия.Умное самолечение (Auto-Remediation): Автоматический перезапуск Docker-контейнера при достижении порога ошибок.Защита от ложных срабатываний: Проверка внешнего интернета исключает алерты при сбоях на стороне самого сервера мониторинга.DPI-Friendly: Проверка Reality выполняется в гибридном режиме (раз в 5 минут), что минимизирует риск обнаружения системами глубокой инспекции трафика.Поддержка протоколов: Полная совместимость с TCP (Reality/VLESS) и UDP (Hysteria 2/QUIC).Масштабируемость: Готовый Jinja2-шаблон для деплоя через Ansible или Semaphore на любое количество нод.🛠 Техническая логикаСкрипт выполняет проверки в строгой последовательности. Если на каком-то этапе обнаружена критическая проблема, проверка прерывается, чтобы не плодить лишние сущности:Internet Check: Стучится в 1.1.1.1. Если связи нет — статус No_internet.Bridge Check: Проверяет доступность удаленного моста (выходной ноды). Поддерживает -zu для UDP.Container Check: Проверяет статус Running через docker inspect.Hybrid Port Check: * 90% времени: Быстрый L4-чек (порт открыт/закрыт).10% времени: Глубокий L7-чек (TLS handshake через OpenSSL + фоллбэк на Curl с маскировкой под браузер).📖 Пошаговое руководство по установке1. Подготовка (Manual)Убедитесь, что на сервере установлены необходимые утилиты:Bashapt update && apt install -y jq netcat-openbsd curl docker.io
2. Настройка инвентаря (Ansible/Semaphore)Для автоматизации используйте следующие переменные в вашем inventory.yml:YAMLhosts:
  vpn-node-01:
    ansible_host: 1.2.3.4
    kuma_push_url: "https://kuma.example.com/api/push/key?v=1"
    vpn_port: 443
    vpn_proto: "tcp"           # tcp для Reality, udp для Hysteria
    sni: "yahoo.com"
    bridge_ip: "5.6.7.8"       # Опционально: IP выходного моста
    bridge_port: 443
    bridge_port_proto: "udp"   # Протокол моста
3. Деплой через AnsibleИспользуйте плейбук для копирования шаблона и настройки Cron:YAML- name: Deploy Monitoring
  hosts: all
  tasks:
    - name: Upload Script
      template:
        src: smart_push.sh.j2
        dest: /opt/smart_push.sh
        mode: '0755'

    - name: Add to Cron
      cron:
        name: "Smart Monitor"
        minute: "*"
        job: "/opt/smart_push.sh"
